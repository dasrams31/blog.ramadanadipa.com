# blog.ramadanadipa.com

Source of the personal tech blog — static site generator + articles (Bahasa Indonesia).

**Live:** https://blog.ramadanadipa.com/

## Contents
- `build.py` — static site generator (stdlib only, no dependencies)
- `content/` — articles in Markdown (`YYYY-MM-DD-slug.md`) with SEO frontmatter + FAQ
- `templates/` — HTML templates
- `static/` — CSS, assets
- `topics.md` — article topic bank (niche: Laravel, React/Next.js, PostgreSQL, AI, VPS/DevOps, karier)

## Build
```bash
python3 build.py
```
Output goes to the web root (served by `blog-web.service`). A daily cron writes one new article from `topics.md` and rebuilds automatically.

## Not included
- Built HTML output (regenerated by `build.py`)
